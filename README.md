# Onyeka M. Obasi

An academic website based on [Hunter Ng's Jekyll site](https://github.com/hunternbh/hunterng), using the Academic Pages and Minimal Mistakes template. The About, Research, Teaching, and CV pages reproduce the public content of [onyekaobasi.com](https://onyekaobasi.com/) as of November 11, 2026.

## Publish a fork

1. Fork this repository using the **Fork** button on GitHub.
2. In the fork, go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
3. Open the URL shown in **Settings → Pages** once the deployment completes. Edit the files in `_pages/` to update the content, and `_config.yml` to update the sidebar.

For a local preview, install Ruby and Bundler, then run `bundle install` and `bundle exec jekyll serve`. Open `http://localhost:4000/`.
